APG Slide Mailer

A personal tool for emailing weekly research slide decks.

APG Slide Mailer is a small command-line script that its owner runs on their own computer to create Gmail drafts and send emails with a weekly PowerPoint deck attached. It uses the Gmail API with the gmail.compose permission and acts only on the owner's own Gmail account.

It is not a public service and has no other users.
