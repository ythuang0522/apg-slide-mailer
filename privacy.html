Privacy policy

APG Slide Mailer · last updated 2 October 2026

What the app does

APG Slide Mailer runs only on its owner's computer. With the owner's consent it uses Google's gmail.compose permission to create drafts and send messages from the owner's own Gmail account, attaching a file the owner chooses.

Data accessed

  • It sends the recipients, subject, body and attachment the owner specifies.
  • After sending, it reads back that one message's metadata (labels, recipients, subject, size) to confirm delivery.
  • It reads the account's email address to show which account is signed in.
  • It does not read, search, or download other messages in the mailbox.

Storage and sharing

The OAuth token is stored only on the owner's computer, in a file readable only by the owner. No Google user data is sent to any server other than Google's, and none is sold, shared, or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
